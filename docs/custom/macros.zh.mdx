---
title: 宏
description: 由你编写并排练过的手势序列，智能体一次调用即可重放，省时省 token。
---

token 很贵。宏把多个手势合并进一次模型调用，于是智能体直接调用你编写并排练好的序列，而不必逐步驱动手机。宏能省下 token，也省下时间。

## 创建宏

先生成脚手架，再编辑其中的 `MACRO.yml` 文件：

```bash
physiclaw macros init notify-user-wechat
```

<FileTree>
- ~/.physiclaw/macros/
  - README.md
  - notify-user-wechat/
    - MACRO.yml
</FileTree>

### MACRO.yml

```yaml
name: notify-user-wechat
# 智能体只凭这一行挑选宏，所以要写清楚什么时候用、做什么。
description: 需要用微信给你的用户发消息时使用。打开聊天并把文本粘好，停在发送之前

# false 表示智能体看不到、也调不了它。
enabled: true

# 这个宏需要的参数。
inputs:
  message:
    description: 要发送的消息文本
    example: "订单已下，共 ¥30"

# 自上而下依次执行，每步一个动作。
steps:
  - name: start-home
    tool: home_screen

  - name: open-wechat
    tool: tap
    with:
      # [左, 上, 右, 下]，取值是 0–1 的屏幕比例。
      bbox: [0.62, 0.18, 0.85, 0.30]

  - name: await-wechat
    tool: wait
    with:
      seconds: 2
    # 微信会停在上次离开的界面，标题栏可能是应用名，也可能是对方昵称。
    expect:
      {or: ["微信", "Weixin", "对方昵称"],
       within: [0.15, 0.02, 0.85, 0.1]}
    hint: "微信没有打开，先登录再手动发送"

  - name: open-chat
    tool: tap
    with:
      bbox: [0.05, 0.10, 0.95, 0.20]
    # 已经在聊天里就跳过。
    skip_when:
      {text: "对方昵称", within: [0.15, 0.02, 0.85, 0.1]}
    # 确认点的是正确的列表项。
    guard:
      require: {text: "对方昵称", within: [0.05, 0.10, 0.95, 0.20]}

  - name: stage-text
    tool: send_to_clipboard
    with:
      text: "{message}"

  - name: focus-input
    tool: tap
    with:
      bbox: [0.05, 0.90, 0.75, 0.96]
    # 键盘已弹起（能看到空格键）就跳过。
    skip_when:
      {or: ["space", "空格"], within: [0.25, 0.85, 0.8, 0.95]}

  - name: paste-menu
    tool: long_press
    with:
      bbox: [0.05, 0.56, 0.75, 0.62]

  - name: paste
    tool: tap
    with:
      bbox: [0.10, 0.54, 0.20, 0.57]
    guard:
      require: {text: "粘贴", within: [0.03, 0.50, 0.35, 0.62]}

# 刻意不写发送步骤：由智能体确认文本后决定是否发送。
```

可用工具：`tap`、`double_tap`、`long_press`、`swipe`、`home_screen`、`go_back`、`force_quit`、`send_to_clipboard`、`peek` 和 `wait`。

## 排练

先启动 MCP 服务：

```bash
physiclaw mcp
```

再校验每个 `MACRO.yml`，并在真机上重放这一个：

```bash
physiclaw macros check
physiclaw macros run notify-user-wechat -i message=hi
```

## 最佳实践

**保持宏短小、单一用途。** 途中需要判断的事，如确认、支付、多选一，属于智能体，不属于宏。

**让智能体来写。** 把 `claude` 或 `codex` 接上你的 MCP 服务，然后让它来写这个宏。

**先排练，后启用。** 硬编码的 bbox 之所以可靠，是因为你在这台设备、这部手机、这套布局上验证过。

**关注统计。** `physiclaw macros stats` 显示每个宏的计数。`consecutive_aborts` 持续上升说明 App 布局变了，需要重新排练并更新 bbox。
