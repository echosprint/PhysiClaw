一切都已就绪。

启动服务：

```bash
physiclaw
```

它会在浏览器打开**硬件设置**页面。开启**自动模式**，点击**继续**，它会自动跑完全部步骤，需要你时才停下。

也可以跳过浏览器，直接在终端开启自动模式：

```bash
physiclaw auto
```

下次启动时，只要上次运行后设备没动过，就能跳过设置和校验，立即开始：

```bash
physiclaw now
```

## 任务示例

确认 PhysiClaw 手机已登录**微信**，你会用到的 App（美团、京东、淘宝等）也都提前登录好，并设置默认收货地址和支付方式。

用你自己的微信，和 PhysiClaw 手机上的微信互加好友，然后像聊天一样发消息告诉它做什么：

```text
帮我在美团上点一杯瑞幸美式。
明天天气怎么样？
明早 7 点把最新新闻发给我。
在京东七鲜买牛奶和鸡蛋。
帮我在 DeepSeek 上搜一下「xx 问题」。
```

:::tip[还没配置模型？]
智能体需要一个大模型提供商。如果还没配置，请见[获取 API Key](/zh/set-up/provider/)。
:::
