# Weather

Source: **the installed weather app** (iOS 天气/Weather, or the app the user names) — never a browser search.

1. Open it (`open-app` if the icon isn't visible).
2. Confirm the CITY in the header (user's own if unnamed). Wrong → pick from the list icon (bottom-right); not listed → ask.
3. Today → main screen (`swipe` up for AQI / precip / wind). A coming day → `tap` its row in the 10-day list.
4. Reply with exact figures as displayed — condition, high/low, precip %, AQI — plus the timing that matters ("rain 14:00–18:00").
